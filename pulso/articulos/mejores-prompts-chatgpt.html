Los 50 mejores prompts para ChatGPT en 2026

Prompts listos para copiar y pegar, organizados por categoría y optimizados para GPT-4o. Desde productividad profesional hasta creatividad, aquí tienes los que realmente funcionan.

Por Equipo Pulso 10 jun 2026 10 min de lectura

Categorías

  1. Productividad y trabajo
  2. Escritura y contenido
  3. Marketing y ventas
  4. Programación y código
  5. Estudio y aprendizaje
  6. Creatividad e ideas
  7. Cómo escribir mejores prompts

Un buen prompt es la diferencia entre una respuesta genérica y una que realmente te sirve. La clave es ser específico, dar contexto y decirle al modelo qué formato quieres. Los siguientes 50 prompts están diseñados para GPT-4o y puedes usarlos tal cual o adaptarlos a tu situación.

1. Productividad y trabajo

PROMPT 01Actúa como un consultor de productividad. Analiza mi lista de tareas del día: [lista] y dime cuáles debo hacer primero usando la matriz de Eisenhower. Explica tu razonamiento.
PROMPT 02Redacta un email profesional para rechazar una reunión sin quedar mal. El contexto es: [situación]. Tono: educado pero firme. Máximo 100 palabras.
PROMPT 03Crea un orden del día para una reunión de 45 minutos sobre [tema]. Incluye objetivo, puntos a tratar con tiempos asignados y una acción concreta de cierre.
PROMPT 04Resume este documento en 5 puntos clave con el formato "Lo más importante es...". El documento es: [pega el texto].
PROMPT 05Actúa como mi jefe. Revisa este informe: [texto] y dame feedback directo sobre qué mejorar antes de enviarlo a la dirección.
PROMPT 06Crea una plantilla de seguimiento semanal para un freelance que trabaja con 3 clientes distintos. Incluye apartados de horas, tareas completadas, pendientes y facturación.
PROMPT 07Dame 10 formas de decir "no tengo tiempo para esto ahora" de manera profesional y sin dañar la relación con el cliente.
PROMPT 08Transforma estas notas de reunión desordenadas en un acta formal con: asistentes, decisiones tomadas y próximos pasos. Notas: [pega las notas].

2. Escritura y contenido

PROMPT 09Escribe una introducción para un artículo sobre [tema] que empiece con una estadística impactante, plantee un problema y prometa una solución. Tono periodístico, 150 palabras.
PROMPT 10Reescribe este párrafo en tres versiones: una formal, una casual y una para redes sociales. Párrafo: [texto].
PROMPT 11Actúa como editor jefe. Lee este texto y señala: 1) frases demasiado largas, 2) palabras repetidas, 3) ideas poco claras. Sé directo. Texto: [pega el texto].
PROMPT 12Genera 10 titulares para un artículo sobre [tema]. La mitad deben ser basados en números, la otra mitad en preguntas. Optimizados para SEO.
PROMPT 13Escribe una descripción de producto de 200 palabras para [producto]. Destaca el beneficio principal, usa lenguaje sensorial y termina con una llamada a la acción.
PROMPT 14Crea un hilo de Twitter/X de 8 tweets sobre [tema]. El primero debe enganchar, los intermedios aportar valor y el último pedir interacción.
PROMPT 15Escribe una newsletter semanal de 400 palabras sobre las novedades en [sector]. Estructura: apertura personal, 3 noticias con contexto, reflexión final y CTA.

3. Marketing y ventas

PROMPT 16Crea una propuesta de valor para [producto/servicio] usando la fórmula: "Ayudamos a [cliente ideal] a [resultado] sin [obstáculo]". Dame 5 versiones distintas.
PROMPT 17Analiza esta página de ventas: [URL o texto] y dime qué elementos cambiarías para aumentar la conversión. Sé específico con cada sección.
PROMPT 18Genera 20 ideas de contenido para Instagram para una marca de [nicho]. Mezcla: educativo (40%), entretenimiento (30%) e inspiracional (30%).
PROMPT 19Escribe un email de seguimiento post-reunión de ventas para [nombre del cliente]. Recuerda los puntos hablados: [puntos]. Tono cálido pero con sentido de urgencia suave.
PROMPT 20Crea un argumentario de ventas para [producto] que responda a las 5 objeciones más comunes: precio, tiempo, confianza, necesidad y competencia.
PROMPT 21Dame 15 hooks para vídeos de TikTok/Reels sobre [temática]. Que los primeros 3 segundos generen curiosidad o sorpresa.

4. Programación y código

PROMPT 22Eres un senior developer. Revisa este código y dime: bugs, mejoras de rendimiento y si sigue las mejores prácticas. Código: [pega el código].
PROMPT 23Explica qué hace este código línea por línea, como si se lo explicaras a alguien sin conocimientos técnicos. Código: [pega el código].
PROMPT 24Escribe una función en [lenguaje] que [descripción de la función]. Incluye comentarios, manejo de errores y un ejemplo de uso.
PROMPT 25Convierte esta consulta SQL en lenguaje natural y dime si se puede optimizar para una tabla con 10 millones de registros. SQL: [pega la consulta].
PROMPT 26Crea un script en Python que [tarea]. Requisitos: sin librerías externas, debe manejar errores y mostrar progress en consola.
PROMPT 27Dame una lista de 10 preguntas técnicas de entrevista para [puesto] con sus respuestas modelo. Nivel: [junior/senior].

5. Estudio y aprendizaje

PROMPT 28Explícame [concepto complejo] como si tuviera 12 años. Usa analogías del mundo real y evita jerga técnica.
PROMPT 29Crea un plan de estudio de 4 semanas para aprender [tema] desde cero. Incluye recursos, tiempos diarios y forma de evaluar el progreso.
PROMPT 30Genera 20 preguntas tipo test sobre [tema] con 4 opciones cada una. Marca la respuesta correcta y explica por qué las otras son incorrectas.
PROMPT 31Resume este libro/artículo en: 3 ideas principales, 5 citas clave y 3 acciones que puedo tomar mañana. Texto: [pega el texto].
PROMPT 32Actúa como profesor de [materia]. Voy a hacerte una pregunta y quiero que no me des la respuesta directamente, sino que me guíes con preguntas para que llegue solo. Pregunta: [tu pregunta].
PROMPT 33Crea tarjetas de memoria (flashcards) sobre [tema]. Formato: pregunta por un lado, respuesta por el otro. Dame 15 tarjetas ordenadas de conceptos básicos a avanzados.
PROMPT 34Compara [concepto A] vs [concepto B] en una tabla con columnas: definición, cuándo usar cada uno, ventajas, desventajas y ejemplo práctico.

6. Creatividad e ideas

PROMPT 35Actúa como un consultor de innovación. Dame 10 ideas de negocio para [nicho] que se puedan lanzar con menos de 500€ de inversión inicial.
PROMPT 36Usa la técnica SCAMPER para generar nuevas ideas sobre [producto/servicio existente]. Aplica cada letra del acrónimo y dame al menos 2 ideas por letra.
PROMPT 37Escribe una historia corta (500 palabras) ambientada en [lugar/época] que transmita el valor de [concepto]. Tono: [serio/humor/inspiracional].
PROMPT 38Dame 30 nombres para un [tipo de negocio/proyecto] en el sector [nicho]. Mezcla: nombres en español, inglés e híbridos. Que sean memorables y disponibles como dominio.
PROMPT 39Diseña una dinámica de team building de 2 horas para un equipo remoto de 8 personas. Sin presupuesto, todo online, que fomente confianza y comunicación.
PROMPT 40Actúa como un guionista de Netflix. Desarrolla el pitch de una serie de 6 episodios sobre [tema]. Incluye: premisa, personajes principales, arco narrativo y gancho de cada episodio.

Prompts avanzados para usuarios expertos

PROMPT 41Antes de responder, piensa paso a paso en voz alta. Luego dame la respuesta final. Pregunta: [tu pregunta compleja].
PROMPT 42Juega al abogado del diablo. Dame los 5 argumentos más sólidos en contra de [idea que defiendes]. Sé implacable.
PROMPT 43Analiza esta decisión usando el método de los 6 sombreros de De Bono. Decisión: [tu decisión]. Un párrafo por cada sombrero.
PROMPT 44Actúa como un panel de 3 expertos en [campo]: uno optimista, uno pesimista y uno pragmático. Debatid sobre [tema]. Quiero sus tres perspectivas.
PROMPT 45Crea un prompt mejorado a partir de este: [tu prompt original]. El nuevo debe ser más específico, incluir contexto, formato deseado y criterios de calidad.
PROMPT 46Identifica los sesgos cognitivos presentes en este argumento: [texto]. Lista cada sesgo, explica por qué lo detectas y cómo corregirlo.
PROMPT 47Actúa como un inversor de venture capital. Evalúa esta idea de negocio: [descripción] con una puntuación del 1 al 10 en: mercado, equipo, producto, timing y competencia. Razona cada nota.
PROMPT 48Simula una sesión de preguntas difíciles de una entrevista para el puesto de [cargo]. Hazme las preguntas una a una y espera mi respuesta antes de continuar.
PROMPT 49Escribe un análisis DAFO completo para [empresa/proyecto] basándote en esta información: [datos]. Formato: tabla con cada cuadrante y 5 puntos por sección.
PROMPT 50Actúa como un editor que acaba de leer mi manuscrito/proyecto. Dame el feedback más honesto y útil posible, sin suavizar nada. Texto: [pega tu texto].

Cómo escribir mejores prompts

Los prompts anteriores funcionan porque siguen estas reglas:

  1. Asigna un rol: "Actúa como un..." mejora la calidad de las respuestas un 40-60%.
  2. Da contexto: Cuanto más sepa el modelo de tu situación, más precisa será la respuesta.
  3. Especifica el formato: "En formato tabla", "en 5 puntos", "máximo 200 palabras".
  4. Indica el tono: formal, casual, técnico, divulgativo, humorístico.
  5. Pide paso a paso: Para tareas complejas, añade "piensa paso a paso antes de responder".
